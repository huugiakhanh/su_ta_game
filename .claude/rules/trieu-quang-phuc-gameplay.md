## Nội dung lịch sử

- `assets/question/trieu-quang-phuc-question.json` **chuyển từ Excel** sheet "4 Triệu Việt Vương" (A3:H52) bằng script đọc xlsx, đối chiếu 50/50 câu (TQP-SKELETON). `questions-data.js` **sinh bằng** `python tools/make_question_data.py trieu-quang-phuc`; không sửa tay. **Giữ đủ 50 câu**. **Team tự sửa JSON** khi chỉnh câu hỏi (người dùng chốt 05/11) — Claude không sửa nội dung câu; sửa JSON xong phải chạy lại script trên thì màn chơi mới đổi (`/quiz` đọc JSON trực tiếp).
